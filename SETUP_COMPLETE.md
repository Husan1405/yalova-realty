## 🤖 TELEGRAM БОТ И API

### Команды бота
```
/start   - Главное меню
/add     - Добавить квартиру (интерактивно)
/list    - Список всех квартир
/delete  - Удалить квартиру
/help    - Справка
```

### REST API
```
GET  /api/apartments      - Получить все квартиры
POST /api/apartments      - Добавить квартиру
DEL  /api/apartments/:id  - Удалить квартиру
```

### Процесс добавления квартиры через бота:
1. `/add` → Выбрать тип → Выбрать статус → Ввести название, описание, цену
2. (Опционально) Добавить комнаты, площадь, фото
3. Квартира сохраняется в `apartments.json`
4. Автоматически появляется на сайте при следующей загрузке

## 🎬 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Добавить квартиру через curl
```bash
curl -X POST http://localhost:5000/api/apartments \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Квартира",
    "description": "2-комнатная",
    "price": "$100,000",
    "type": "apartment",
    "status": "sale",
    "rooms": "2",
    "area": "75"
  }'
```

### Получить все квартиры
```bash
curl http://localhost:5000/api/apartments
```

### Удалить квартиру
```bash
curl -X DELETE http://localhost:5000/api/apartments/1704067800123
```

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

| Проблема | Решение |
|----------|---------|
| "Бот не отвечает" | Убедитесь, что `npm start` запущен |
| "Cannot find module" | Выполните `npm install` в папке backend |
| "Port 5000 already in use" | Измените PORT в .env или закройте другой процесс |
| "Квартиры не видны на сайте" | Перезагрузите страницу (Ctrl+R) |
| "JSON.parse error" | Очистите localStorage: `localStorage.clear()` |

👉 Полный список решений в **INSTRUCTIONS.md**
