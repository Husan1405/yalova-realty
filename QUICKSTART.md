# 🚀 Быстрый старт - Yalova Realty

## За 5 минут до первого тестирования

### Шаг 1: Запустить Telegram бота

```bash
# Перейти в папку backend
cd backend

# Установить зависимости (первый раз)
npm install

# Запустить бота
npm start
```

Если все работает, вы увидите:
```
🤖 Bot started
🌐 API Server running on http://localhost:5000
```

### Шаг 2: Открыть Telegram

1. Откройте Telegram на телефоне или в браузере
2. Найдите бота: **[REDACTED_BOT]**
3. Нажмите `/start`

### Шаг 3: Добавить тестовую квартиру

1. Нажмите `/add` в боте
2. Выберите "🏠 Квартира"
3. Выберите "💰 На продажу"
4. Введите название: "Квартира с видом на море"
5. Введите описание: "3-комнатная квартира в новом комплексе"
6. Введите цену: "$150,000"
7. Введите комнаты: "3"
8. Введите площадь: "95"
9. Пропустите фото (кнопка)

Квартира добавлена! ✅

### Шаг 4: Проверить на сайте

1. Откройте `index.html` в браузере
2. Нажмите в меню "Каталог квартир"
3. Вы увидите добавленную квартиру!

## 🎮 Команды бота

- `/start` - Главное меню
- `/add` - Добавить квартиру
- `/list` - Список всех квартир
- `/delete` - Удалить квартиру
- `/help` - Справка

## 💡 Полезные советы

### Добавить сразу много квартир

1. Нажмите `/list` чтобы увидеть ID всех квартир
2. Нажмите `/delete` чтобы удалить старые

### Синхронизировать сайт с ботом

Квартиры синхронизируются автоматически через localStorage. 
Если не обновляются, просто перезагрузите страницу (F5).

### Добавить фото к квартире

При добавлении через бота просто отправьте фото вместо пропуска.
Фото загружается с серверов Telegram.

### Проверить API

```bash
# Получить все квартиры
curl http://localhost:5000/api/apartments

# Добавить квартиру через API
curl -X POST http://localhost:5000/api/apartments \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Вилла",
    "description": "Красивая вилла",
    "price": "$250,000",
    "type": "villa",
    "status": "sale"
  }'

# Удалить квартиру
curl -X DELETE http://localhost:5000/api/apartments/APARTMENT_ID
```

## 🐛 Если что-то не работает

### Бот не запускается
```
Ошибка: Cannot find module 'telegraf'
```
Решение: `npm install` в папке backend

### Бот запущен, но не отвечает
- Проверьте, что токен в `.env` правильный
- Перезагрузите бота
- Проверьте интернет соединение

### Сайт не показывает квартиры
- Перезагрузите страницу (F5)
- Проверьте, что бот запущен
- Откройте DevTools (F12) и проверьте Console

### API недоступен
- Убедитесь, что бот запущен (в консоли должно быть "🌐 API Server")
- Проверьте порт 5000 не занят: `netstat -an | grep 5000`
