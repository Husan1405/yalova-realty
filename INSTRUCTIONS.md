## Установка

### Системные требования

- **Node.js** 16 и выше ([скачать](https://nodejs.org/))
- **npm** (устанавливается с Node.js)
- **Telegram аккаунт**
- Текстовый редактор (VS Code, Sublime Text и т.д.)

### Проверка установки

```bash
node --version      # должно быть v16+
npm --version       # должно быть 7+
```

### Установка зависимостей

```bash
# Откройте терминал в папке backend
cd path/to/yalova-realty/backend

# Установите зависимости
npm install

# Проверка (должны быть зеленые галочки)
npm list
```

## Добавление квартир

### Способ 1: Через Telegram (самый удобный)

#### Шаг за шагом

1. **Начните добавление**
   ```
   /add
   ```
   или нажмите кнопку "➕ Добавить квартиру"

2. **Выберите тип объекта**
   - 🏠 Квартира
   - 🏡 Вилла
   - 🌳 Земельный участок

3. **Выберите статус**
   - 💰 На продажу
   - 📍 На аренду

4. **Заполните информацию**

   | Поле | Пример | Обязательно? |
   |------|--------|-------------|
   | Название | "Квартира с видом на море" | ✅ |
   | Описание | "3-комнатная, в новом комплексе" | ✅ |
   | Цена | "$150,000" или "₺2,000,000" | ✅ |
   | Комнаты | "3" | ❌ |
   | Площадь | "95" (м²) | ❌ |
   | Фото | Отправьте изображение | ❌ |

5. **Подтверждение**
   
   После ввода всей информации вы увидите:
   ```
   ✅ Квартира добавлена!
   
   Название квартиры
   Описание
   Цена
   
   Объект появится на сайте через несколько секунд.
   ```

#### Советы по добавлению

- **Описание**: Будьте подробнее!
  - Плохо: "Квартира"
  - Хорошо: "Красивая 3-комнатная квартира в ЖК Премиум с видом на море"

- **Цена**: Указывайте валюту
  - "$150,000" (доллары)
  - "€130,000" (евро)
  - "₺2,500,000" (турецкие лиры)

- **Фото**: 
  - Лучше добавить хотя бы одно фото
  - Можно отправить несколько (первое будет основным)
  - Разрешены JPEG, PNG

## Синхронизация

### Как это работает

```
┌─────────────────────┐
│  Telegram Бот       │
│  (Ваше управление)  │
└──────────┬──────────┘
           │
           │ Сохраняет в
           ▼
    apartments.json
           │
           │ API
           │ GET /api/apartments
           ▼
    ┌─────────────────┐
    │   Веб-сайт      │
    │ (Отображение)   │
    └─────────────────┘
```

### Автоматическая синхронизация

1. Вы добавляете квартиру через бота
2. Она сохраняется в `backend/apartments.json`
3. Сайт загружает данные из localStorage
4. Данные появляются на сайте

### Ручная синхронизация

Если данные не обновляются:

1. **На сайте**: Нажмите F5 (перезагрузка страницы)
2. **На боте**: Перезагрузите бота (Ctrl+C, потом `npm start`)

### Проверка синхронизации

```bash
# Посмотреть содержимое БД
cat backend/apartments.json

# Запросить через API
curl http://localhost:5000/api/apartments | python -m json.tool
```

## Развертывание

### На локальной машине (разработка)

```bash
# Терминал 1: Запустить бота
cd backend
npm install
npm start

# Терминал 2: Открыть сайт
# Просто откройте index.html в браузере
# Или используйте HTTP сервер:
python -m http.server 8000
# Сайт будет на http://localhost:8000
```

### На сервере (production)

#### Требования
- Node.js 16+
- PM2 или systemd для управления процессом
- Веб-сервер (nginx или Apache)

#### Установка

```bash
# SSH на сервер
ssh user@your-server

# Клонируйте проект
git clone <your-repo> yalova-realty
cd yalova-realty/backend

# Установите зависимости
npm install --production

# Установите PM2 (глобально)
npm install -g pm2

# Запустите бота
pm2 start bot.js --name "yalova-bot"
pm2 save
pm2 startup
```

#### Конфигурация nginx

```nginx
server {
    listen 80;
    server_name yalova-realty.com www.yalova-realty.com;

    # Сайт (статические файлы)
    location / {
        root /path/to/yalova-realty;
        index index.html;
    }

    # API (бот)
    location /api/ {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

#### SSL (HTTPS)

```bash
# Используйте Let's Encrypt
sudo certbot certonly --standalone -d yalova-realty.com
```

## Поиск и устранение неисправностей

### Проблема: "Бот не отвечает"

**Причины:**
- Бот не запущен
- Интернет отключен
- Неправильный токен

**Решение:**

```bash
# 1. Проверьте, что бот запущен
# В консоли должны быть сообщения "🤖 Bot started"

# 2. Проверьте файл .env
cat backend/.env
# BOT_TOKEN должен быть: [REDACTED_TOKEN]

# 3. Перезагрузите бота
# Нажмите Ctrl+C и запустите заново
npm start

# 4. Проверьте интернет
ping google.com
```

### Проблема: "Cannot find module"

**Решение:**

```bash
# Переустановите зависимости
rm -rf node_modules package-lock.json
npm install
npm start
```

### Проблема: "Port 5000 already in use"

**Решение:**

```bash
# Найдите процесс, использующий порт 5000
# На Windows:
netstat -ano | findstr :5000

# На macOS/Linux:
lsof -i :5000

# Завершите процесс и запустите бота заново
```

### Проблема: "Квартиры не отображаются на сайте"

**Решение:**

1. Перезагрузите сайт (F5)
2. Откройте DevTools (F12)
3. Проверьте вкладку "Application" → "LocalStorage"
4. Там должны быть квартиры в ключе "apartments"

```javascript
// В консоли браузера:
console.log(localStorage.getItem('apartments'))
```

### Проблема: "Какие-то ошибки в консоли"

**Решение:**

Откройте DevTools (F12) → Console и посмотрите ошибки:

- "Fetch failed" → Бот не запущен
- "JSON.parse error" → Проблема с данными в localStorage
- "localStorage is full" → Очистить: `localStorage.clear()`
