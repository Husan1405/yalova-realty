### 🤖 Telegram Бот создан и функционален

**Основной файл:** `backend/bot.js` (~550 строк кода)

**Доступные команды:**
```
/start   - Главное меню с кнопками
/add     - Добавить новую квартиру (интерактивно)
/list    - Список всех квартир с ID
/delete  - Удалить выбранную квартиру
/help    - Справка по командам
```

**Процесс добавления квартиры:**
1. Выбор типа (Квартира, Вилла, Участок)
2. Выбор статуса (На продажу, На аренду)
3. Ввод названия, описания, цены
4. (Опционально) Комнаты, площадь, фото

**Автоматизация:**
- Сохранение квартир в JSON файл
- REST API для синхронизации с сайтом
- Поддержка фото из Telegram

### 📊 REST API

**3 основных endpoint'а:**
```
GET  /api/apartments       - Получить все квартиры
POST /api/apartments       - Добавить квартиру (API)
DEL  /api/apartments/:id   - Удалить квартиру
```

**Запуск API:**
- Автоматически запускается с ботом
- Доступен на `http://localhost:5000`
- Возвращает JSON

### 💾 База данных

**Файл:** `backend/apartments.json`
**Формат:** JSON массив объектов квартир
**Структура каждой квартиры:**
- id, title, description, price
- type (apartment/villa/land)
- status (sale/rent)
- rooms, area, image (опционально)
- createdAt, createdBy
