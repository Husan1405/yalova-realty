# 🏠 Yalova Realty - Каталог недвижимости Ялова

Полнофункциональный сайт для продажи и аренды недвижимости в Ялове, Турция с интеграцией Telegram бота для управления каталогом.

## ✨ Особенности

- 🎨 Современный, красивый дизайн с плавными анимациями
- 📱 Полностью адаптивный для мобильных устройств
- 🌍 Раздел "О городе" с информацией и погодой
- 📍 Интересные места в Ялове
- 🏠 Каталог квартир, вилл и участков
- 💬 Встроенная система поддержки через Telegram
- 🤖 Управление каталогом через Telegram бота
- 🔄 Синхронизация квартир в реальном времени

## 🚀 Быстрый старт

### Фронтенд (Сайт)

Сайт это статический HTML файл, просто откройте `index.html` в браузере или используйте простой HTTP сервер:

```bash
# Если у вас есть Python
python -m http.server 8000

# Или Node.js
npx http-server
```

Сайт будет доступен на `http://localhost:8000`

### Бэкенд (Telegram Бот)

```bash
cd backend
npm install
npm start
```

Бот запустится и будет слушать команды Telegram.

## 📱 Структура каталога

### На сайте

Каталог квартир находится в отдельном разделе с:
- Сеткой карточек квартир
- Фильтрацией по типу (квартира, вилла, участок)
- Фильтрацией по статусу (продажа, аренда)
- Поиском по названию и описанию
- Кнопкой для связи с нами

Данные хранятся в `localStorage` браузера и синхронизируются с API бота.

### В Telegram боте

Управляйте каталогом прямо из мессенджера:
- `/start` - Главное меню
- `/add` - Добавить новую квартиру
- `/list` - Просмотреть все квартиры
- `/delete` - Удалить квартиру

Когда вы добавляете квартиру через бота, она автоматически появляется на сайте.

### Процесс

1. **Добавление через бота**: Вы добавляете квартиру в Telegram → Сохраняется в `apartments.json`
2. **API запрос**: Сайт (или вы) запрашивает квартиры через `GET /api/apartments`
3. **Отображение**: Квартиры отображаются на сайте из localStorage

## 🌐 REST API

Бот предоставляет REST API для работы с каталогом:

### GET /api/apartments
```bash
curl http://localhost:5000/api/apartments
```

### POST /api/apartments
```bash
curl -X POST http://localhost:5000/api/apartments \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Квартира",
    "description": "Описание",
    "price": "$100,000",
    "type": "apartment",
    "status": "sale"
  }'
```

### DELETE /api/apartments/:id
```bash
curl -X DELETE http://localhost:5000/api/apartments/1234567890
```

## 📝 Примечания

- Сайт работает как статический файл, но может быть развернут на любом хостинге

## 🚀 Развертывание

### На локальной машине

1. Клонируйте/скопируйте проект
2. Установите зависимости: `cd backend && npm install`
3. Запустите бота: `npm start`
4. Откройте `index.html` в браузере

### На сервере

1. Загрузите проект на сервер
2. Установите Node.js
3. Запустите бота через PM2 или systemd
4. Разверните сайт на веб-сервер (nginx, Apache)
5. Настройте обратный прокси для API
