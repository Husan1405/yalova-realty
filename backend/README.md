# Telegram Бот для управления каталогом квартир

Полнофункциональный Telegram бот для управления каталогом недвижимости на сайте yalova-realty.

## 🚀 Установка и запуск

### Предварительные требования
- Node.js 16+ 
- npm или yarn
- Telegram аккаунт

### Шаг 1: Установка зависимостей

```bash
cd backend
npm install
```

### Шаг 2: Конфигурация

Отредактируйте файл `.env`:

```env
BOT_TOKEN=[REDACTED_TOKEN]
BOT_USERNAME=[REDACTED_BOT]
WEBSITE_URL=http://localhost:5000
ADMIN_ID=
PORT=5000
```

- **BOT_TOKEN**: Токен бота от BotFather (уже заполнен)
- **BOT_USERNAME**: Username бота (уже заполнен)
- **WEBSITE_URL**: URL вашего сайта
- **ADMIN_ID**: (опционально) Telegram ID администратора для уведомлений
- **PORT**: Порт API сервера

### Шаг 3: Запуск бота

```bash
npm start
```

Для режима разработки с автоперезагрузкой:

```bash
npm run dev
```

## 📱 Использование Telegram Бота

### Основные команды

- `/start` - Главное меню
- `/add` - Быстро добавить квартиру
- `/list` - Список всех квартир
- `/delete` - Удалить квартиру
- `/help` - Справка

### Процесс добавления квартиры

1. Нажмите `/add` или кнопку "➕ Добавить квартиру"
2. Выберите тип: Квартира, Вилла или Участок
3. Выберите статус: На продажу или На аренду
4. Введите название объекта
5. Введите описание
6. Введите цену
7. (Опционально) Введите количество комнат
8. (Опционально) Введите площадь
9. (Опционально) Отправьте фото

После завершения объект автоматически появится на сайте.

### Просмотр каталога

Используйте команду `/list` для вывода всех квартир с ID для удаления.

### Удаление квартиры

1. Нажмите `/delete`
2. Выберите квартиру из списка
3. Подтвердите удаление

Квартира будет удалена как из бота, так и с сайта.

## 🔌 REST API

Бот также предоставляет REST API для синхронизации с сайтом:

### GET /api/apartments
Получить все квартиры в каталоге.

```bash
curl http://localhost:5000/api/apartments
```

**Ответ:**
```json
[
  {
    "id": "1234567890",
    "title": "Квартира с видом на море",
    "description": "3-комнатная квартира в новом комплексе",
    "price": "$150,000",
    "type": "apartment",
    "status": "sale",
    "rooms": "3",
    "area": "95",
    "image": "https://...",
    "createdAt": "2024-01-15T10:30:00.000Z"
  }
]
```

### POST /api/apartments
Добавить новую квартиру (для прямого добавления без бота).

```bash
curl -X POST http://localhost:5000/api/apartments \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Квартира в центре",
    "description": "2-комнатная квартира",
    "price": "$100,000",
    "type": "apartment",
    "status": "sale",
    "rooms": "2",
    "area": "75",
    "image": "https://example.com/photo.jpg"
  }'
```

### DELETE /api/apartments/:id
Удалить квартиру по ID.

```bash
curl -X DELETE http://localhost:5000/api/apartments/1234567890
```

## 💾 Хранение данных

Квартиры сохраняются в JSON файле `apartments.json` в папке `backend`.

## 🔄 Синхронизация с сайтом

Сайт автоматически синхронизируется с ботом:

1. **Добавление**: Когда вы добавляете квартиру через бота, она сохраняется в `apartments.json`
2. **Отображение**: Сайт загружает квартиры из localStorage (вы можете обновить его через API)
3. **Удаление**: Удаление через бота удаляет квартиру и с сайта при следующем обновлении

Для автоматической синхронизации сайта добавьте периодический запрос к API:

```javascript
setInterval(async () => {
  const response = await fetch('/api/apartments');
  const apartments = await response.json();
  localStorage.setItem('apartments', JSON.stringify(apartments));
  // Перезагрузить каталог на странице
}, 30000); // каждые 30 секунд
```
