## 🚀 Как начать использовать

### Шаг 1: Установите Node.js
Если еще не установлен: https://nodejs.org/ (выберите LTS версию)

### Шаг 2: Откройте терминал и перейдите в папку backend
```bash
cd d:\games\yalova-realty\backend
```

### Шаг 3: Установите зависимости
```bash
npm install
```

### Шаг 4: Запустите бота
```bash
npm start
```

Если все работает, вы увидите:
```
🤖 Bot started
🌐 API Server running on http://localhost:5000
```

### Шаг 5: Откройте Telegram и найдите бота
1. Откройте Telegram (мобильное приложение или web версия)
2. Найдите бота: **[REDACTED_BOT]**
3. Нажмите кнопку START или напишите `/start`

### Шаг 6: Добавьте первую квартиру
1. Нажмите `/add` или кнопку "➕ Добавить квартиру"
2. Следуйте инструкциям в боте
3. Введите данные квартиры

### Шаг 7: Проверьте на сайте
1. Откройте `d:\games\yalova-realty\index.html` в браузере
2. Нажмите на "Каталог квартир" в меню
3. Вы должны увидеть добавленную квартиру!

## ⚙️ Важные моменты

### Данные хранятся в
- На сервере: `backend/apartments.json`
- На сайте: localStorage браузера

### Синхронизация
Данные синхронизируются автоматически:
1. Вы добавляете квартиру в бота
2. Она сохраняется в JSON файл
3. Сайт загружает данные при открытии/перезагрузке

### Если квартиры не появляются на сайте
1. Перезагрузите страницу (Ctrl+R)
2. Убедитесь, что бот запущен (консоль должна показывать логи)
3. Проверьте браузер консоль (F12) на ошибки

## ❓ Частые вопросы

**Q: Как сделать бота доступным из интернета?**
A: Разверните на сервере (Heroku, AWS, DigitalOcean и т.д.) с domain имением

**Q: Можно ли добавить свою фото?**
A: Да, при добавлении квартиры через бота просто отправьте фото вместо пропуска

**Q: Как сделать резервную копию?**
A: Скопируйте файл `backend/apartments.json` в безопасное место

**Q: Можно ли несколько администраторов?**
A: Да, несколько пользователей могут найти бота и использовать его

**Q: Как добавить еще функций?**
A: Отредактируйте `backend/bot.js` (требуется знание JavaScript)
